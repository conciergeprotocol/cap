# Roster

You may only brief an agent that has listed you.

The roster is `connected_agents` in Cosmic: id, name, a prompt snippet, and the capability flags worth showing. It is an allowlist, not a search index.

Open discovery is out of scope. A2A Agent Cards are how you find a stranger. PAP is how you talk once they are on the roster. Putting a foreign card onto a Cosmic roster is a later product step, not a different rule.

If the roster is empty, the agent has no peers. If the roster is set and the target is missing, the send fails with a list of who *is* available. There is no fallback to "anyone in the project."

This is named access. It is how you avoid a stranger in the workplace.
